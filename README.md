# The Daily Almost

A fictional parody newspaper built with HTML, CSS, and JavaScript.

## Publish with GitHub Pages

In Settings → Pages, choose Deploy from a branch, select main and / (root), and save.

## Edit articles

Articles are stored in the stories array in app.js. Each has a category, headline, description, author, reading time, optional image, and body paragraphs. Keep the satire labels when publishing.

All stories and bylines are fictional. Photographs are illustrative.
